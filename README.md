# CodeAlpha_task-2_Stock_Portfolio_Tracker
A professional Python-based Stock Portfolio Tracker that calculates total investment using predefined stock prices, tracks multiple stocks, validates user input, and generates portfolio summaries with file-saving functionality.
📈 Stock Portfolio Tracker

CodeAlpha Internship – Python Programming Task 2

📌 Project Overview

The Stock Portfolio Tracker is a Python-based application that helps users calculate their total stock investment using predefined stock prices and user-entered quantities.

It provides an interactive, menu-based experience to manage stock investments and view a portfolio summary.

🎯 Objectives

- Track investments in multiple stocks.
- Calculate the investment value for each stock.
- Display the total portfolio investment.
- Provide a simple and user-friendly interface.

✨ Features

- Predefined stock prices using a Python dictionary.
- User input for stock names and quantities.
- Automatic investment calculations.
- Input validation and error handling.
- Interactive portfolio management.
- Portfolio summary.
- Save investment reports to a text file.

🛠️ Technologies Used

- Python 3
- Google Colab
- GitHub

📚 Python Concepts Used

- Dictionaries
- Loops
- Conditional statements
- User input and output
- Basic arithmetic
- Exception handling
- File handling

🚀 How to Run

1. Open the project notebook in Google Colab.
2. Run the code cells.
3. Select a stock from the available stock list.
4. Enter the quantity of shares.
5. Follow the menu options to manage your portfolio.
6. View the total investment and save the report.
